# 来源可信度与标注方法

## 一、为什么要标注

网络小说的元信息（字数、完结状态、付费模式、是否还在连载）变动频繁，一次推荐里混入一条错信息，用户就会失去信任。**标注的作用是把"我确认过的"和"我推测的"分开**，让用户知道哪些可以直接信。

## 二、来源可信度分级

| 级别 | 来源 | 可信度 | 典型问题 |
|---|---|---|---|
| A | 作品官方页面（起点、晋江、番茄等站内作品页） | 最高 | 基本无 |
| B | 平台官方榜单、分类页、官方公告 | 高 | 榜单排名有运营干预 |
| C | 豆瓣读书条目、微信读书条目 | 中高 | 条目可能由用户创建，字数与状态滞后 |
| D | 知乎/贴吧/书友群讨论、书评文章 | 中 | 主观性强，可能有记忆偏差 |
| E | 营销号榜单、聚合导航站、AI 生成的书单文章 | 低 | 大量复制粘贴，书名错、作者错、书已下架 |
| F | 无法追溯来源的印象或推测 | 不可用 | 直接丢弃，不进入候选 |

**E 级来源只能用来发现书名线索，不能用来确认任何字段。** 从 E 级来源拿到的书，必须回到 A 级来源核实后才能输出。

## 三、四档标注的判定细则

### 已核实
同时满足三条：
1. 实际访问了作品官方页面（A 级）
2. 书名、作者与页面一致
3. 付费状态与页面标注一致

输出时不需要解释，直接标。

### 待核实
满足任一条即标：
- 信息来自搜索摘要、社区讨论（C/D 级），未访问官方页
- 访问了官方页但页面要求登录、无法确认付费状态
- 作品页可访问但字数、完结状态与讨论中描述不一致

标注时要**指明哪一项不确定**，例如"待核实：完结状态，社区帖子称已完结但作品页显示仍在更新"。

### 信息不全
缺少以下任一字段：作者、字数、完结状态、可读平台。
标注时列出缺哪几项。

### 来源不明
满足任一条即标：
- 只在单一非官方来源（E 级）出现
- 书名在不同来源写法不一致，疑似记错或同名不同书
- 官方平台搜不到该书，但社区在讨论

标注时说明风险：可能是书名有误、已下架、或仅实体出版。

## 四、交叉核实流程

对每部拟推荐的作品，按顺序走：

1. **锁定书名与作者** — 用书名 + 作者在官方平台站内搜索。搜不到就换关键词（去副标题、加类型词），仍搜不到 → 来源不明
2. **对齐关键字段** — 字数、完结状态、付费模式，以官方页为准，不以讨论帖为准
3. **查口碑** — 至少两个独立来源，注意区分真实书评与营销文案
4. **查雷点** — 搜"书名 + 弃书/雷点"，确认没有撞上用户硬性忌讳
5. **记录来源** — 每条候选记下实际用到的来源，输出时据此定标注档位

## 五、常见信息陷阱

| 陷阱 | 表现 | 应对 |
|---|---|---|
| 同名不同书 | 书名相同但作者不同，是完全两本书 | 一律带作者名检索，输出必带作者 |
| 改名重发 | 同一本书在不同平台叫不同名字 | 输出时列别名，避免用户找不到 |
| 字数虚标 | 平台字数含番外、作者感言 | 按量级理解，不精确到万位 |
| 完结状态滞后 | 页面标"连载中"，实际已断更两年 | 看最近更新日期，超过半年未更提示"疑似断更" |
| 免费状态变动 | 昨天免费今天转付费 | 付费状态标为易变信息，提示以实际打开为准 |
| AI 生成书单 | 书名通顺但查无此书，或作者张冠李戴 | 官方平台搜不到即剔除，不做二次猜测 |

## 六、标注的表达方式

标注写在推荐的末尾，一句话，指明具体不确定项，不要写笼统免责语。

反面：
> 以上信息仅供参考，请以实际为准。

正面：
> **待核实**：完结状态存疑，作品页显示"连载中"但最近更新为 2024 年 11 月，疑似断更。

后者用户立刻知道该注意什么。前者等于没说。

## 七、舆论可信度：识别营销号与争议分类

### 营销号内容 vs 真实书评

判断一条评价能不能计入"舆论质量"，看以下特征：

| 特征 | 营销号/通稿 | 真实书评 |
|---|---|---|
| 缺点 | 只写优点，或写"唯一缺点是不够看" | 会具体指出问题章节或设定漏洞 |
| 细节 | 复读简介原文 | 提到具体情节、配角、第几章 |
| 评分 | 一律 9.5 分以上、带若干星号表情 | 分数分散，有 7 分、8 分 |
| 来源 | 同一篇文字出现在多个站点 | 每个站点角度不同 |
| 日期 | 集中在同一时期批量发布 | 分散在完本后数年内 |
| 标题 | "封神""天花板""不看后悔" | 平实描述或直接吐槽 |

**同通稿多站转载只算一个来源。** 见到三篇措辞高度一致的文章，按单一来源处理（`single_source`）。

### 讨论热度的判定

| 热度 | 判定依据 |
|---|---|
| 高 | 至少 2 个不同平台有独立长评（不是转载），且有持续的后续讨论 |
| 中 | 有讨论但零散，多为短评和打分，缺少长评 |
| 低 | 只有平台评分数字，没有可读的评价内容 |

热度低不等于书差，只说明**样本不足**——这种情况标 `positive_quiet`，不要因为搜不到差评就当成零差评。

### 争议必须分类

同一句"评价两极分化"，背后是两种完全不同的情况：

**口味分歧（不是缺陷）**
- 节奏慢、前期铺垫长
- 文风冷峻、不讨喜
- 设定复杂、需要读者自己推演
- 主角性格不讨喜（但塑造完整）
- 题材小众

这类争议说明书有明确风格取向。合口味的读者评价极高，不合适的读者三章弃。**输出时要写清"适合谁、不适合谁"，而不是当成缺点。**

**质量硬伤（是缺陷）**
- 烂尾、结局崩坏
- 中后期严重注水、剧情原地打转
- 设定前后矛盾、力量体系崩坏
- 主角智商骤降、行为不合理
- 断更、太监

这类争议是客观缺陷，**输出时必须明说，不能用"部分读者认为"模糊化**。

### 判定的信息来源优先级

判断舆论时，可信度从高到低：

1. 平台书评区的长评（有具体情节引用）
2. 豆瓣条目下的书评
3. 贴吧、书友群的讨论帖
4. 知乎相关问题下的回答
5. 推文号、榜单文章（**只能用于发现"有这本书"，不能用于判断好坏**）

前 3 类能支撑 `strong_positive`，只有第 5 类时最高只能给 `single_source`。
