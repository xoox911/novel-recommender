# 平台清单与检索方法

## 零、必检平台清单（硬性要求）

每次检索**必须逐个覆盖以下 4 个平台**，不得只查其中一个就下结论。这四个平台构成完整象限，缺任一个就有一整类作品永远检索不到：

| 级别 | 平台 | 域名 | 主力方向（非独占） | 不检的后果 |
|---|---|---|---|---|
| 必检 | 起点中文网 | qidian.com | 男频 · 付费 | 硬科幻、战舰流、高质量长篇全部漏掉 |
| 必检 | 番茄小说 | fanqienovel.com | 男频 · 免费（女频亦有） | 免费读者无书可看；长篇爽文完本大量遗漏 |
| 必检 | 晋江文学城 | jjwxc.net | 女频 · 付费 | 言情、纯爱、无CP 的细分标签全部漏掉 |
| 必检 | 七猫免费小说 | qimao.com | 女频 · 免费（男频亦有） | 免费女频资源漏掉 |

**番茄和七猫都不是单一象限**，男女频都有货，只是各自强势方向不同。同一个标签在两个方向都要试一轮，否则会漏掉一半。

**判定标准**：**检索动作**必须在 4 个平台全部执行；**产出**允许自然集中——某平台 0 部完全可能，比如男频星际需求下晋江本就以中短篇为主。凡产出少于 1 部的平台，在平台覆盖说明里给出具体原因（题材错配 / 字数门槛 / 站内无匹配标签）即可，**不必反复补查**。

### 不作为日常检索源

掌阅、书旗、咪咕、17K、塔读、黑岩。综合平台为主，自产内容质量参差、搜索噪声大。仅在**已知书名但找不到正版源**时，用于查补充渠道。

## 一、各平台内容侧重

内容侧重与付费模式按平台主流情况归类，**单本书可能有差异，输出前仍需以作品页为准**。

### 起点中文网（男频付费主力）

玄幻仙侠都市历史科幻最强，头部作品集中。付费模式：前若干章免费，后续按章购买（起点币）。硬科幻、星际战舰、太空歌剧的第一来源。

### 番茄小说（免费主力）

男频爽文、女频言情、短剧化节奏。**官方全本免费**。特点：

- 星际、星舰、机甲类供给量大，100 万字以上完本数量超过起点
- 风格偏爽文：数据化、词条、系统、签到、单女主或无女主
- 标签体系粗，找书靠榜单和关键词，不靠精细分类

### 晋江文学城（女频付费主力）

言情、纯爱、无CP，按章付费。**标签体系最完善**，能精确到"无CP+群像+慢热"这种组合，是女频细分需求的首选源。

### 七猫免费小说（免费女频为主）

官方全本免费。未来科幻分类偏女频向（星际养崽、星际种田、星际直播），男频星际机甲作品普遍偏短，20–30 万字居多，长篇少见。

## 二、站内检索方法

**关键原则：不同平台的检索词完全不同，不能一套词打天下。**

| 平台 | 有效检索方式 |
|---|---|
| 起点 | `site:qidian.com <标签> 完本` 或直接访问分类页 `qidian.com/all/` |
| 番茄 | `番茄小说 <标签> 完结` — 站内作品页域名是 `fanqienovel.com/page/<作品ID>`；搜索时带上"番茄小说"前缀，否则被起点内容淹没 |
| 晋江 | `site:jjwxc.net <标签>` — 标签组合直接搜，晋江标签最细 |
| 七猫 | `七猫 <标签> 完结` — 分类页 `qimao.com/shuku/` |

### 为什么必须带平台名

中文网文搜索结果被起点系内容高度垄断。只搜"星际战舰 小说"，返回的几乎全是起点书单和百度百科。**加平台名是最有效的去偏手段。**

### 有效句式

```
<平台名> <细分标签1> <细分标签2> 完结
<类型> 完结 高分 书单
<参考作品名> 类似 推荐
<参考作品名> 为什么好看
<标签> 弃书 / 避雷          # 反向检索，识别雷点
```

### 反向检索的价值

想知道一本书有什么雷，搜"《书名》 弃书"比搜好评有用得多。**先看差评再看好评。**

### 口碑判断

- 至少两个独立来源提到同一优点，才算"多来源正面"
- 只有平台官方推荐语和作者自述 → 不算口碑
- 豆瓣评价人数过少（少于 50 人）→ 口碑**样本不足**，按 `single_source` 或 `positive_quiet` 计，**不得计入 `strong_positive`**。这属于口碑分档问题，不是元信息核实问题，不要错标成「待核实」

## 三、渠道可及性判定

| 情况 | 判定 |
|---|---|
| 用户主用平台上可直接读 | primary（15 分） |
| 需切换到其他平台但能读到 | secondary（8 分） |
| 仅实体书 / 仅海外站 / 已下架 | none（0 分，输出中列为延伸参考并说明原因） |

用户未指定平台时，全部按 primary 计分，此时该维度不构成区分，靠题材与口碑拉开差距。

## 四、海外与翻译渠道

中文网文出海版本（起点国际 Webnovel、Wuxiaworld 等）通常授权有限、更新滞后，须注明"翻译版，与中文原版章节可能有差异"。

**NovelUpdates 等聚合索引站大量条目指向非授权翻译源**，只能用于查作品元信息，不得作为阅读渠道推荐。

## 五、红线

只给正版渠道。以下一律不检索、不提供、不暗示：

- 盗版小说站、TXT 下载站
- 网盘分享链接、群文件
- 破解阅读器与去广告插件
- 任何"免费看全文"的非官方途径

用户主动索要时，一句话说明这是盗版并给出正版选项，不展开、不解释原理。
