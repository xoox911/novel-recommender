# novel-recommender

> 让 AI 按你的口味挑中文网络小说，并且告诉你每本书有什么坑。

一个给 AI Agent 用的 Skill（技能包），适配 WorkBuddy / Claude Code / Codex 等支持 `SKILL.md` 规范的工具。

## 它解决什么问题

让 AI"推荐几本小说"，你通常拿到的是搜索引擎榜单的复述：同质化、无来源、书可能已下架、还可能是营销号编的。

这个 skill 把"找小说"拆成一套可复现的流程：**先问清口味 → 多平台检索 → 硬性过滤 → 加权打分 → 标注每本书的可信度与争议点**。

## 和直接问 AI 的区别

| | 直接问 AI | 用这个 skill |
|---|---|---|
| 偏好收集 | 一次性随口问两句 | 分 3 轮结构化访谈，含雷点勾选与已读去重 |
| 检索范围 | 想到哪搜到哪 | 强制覆盖起点 / 番茄 / 晋江 / 七猫四个必检平台 |
| 排序依据 | 模型感觉 | 六维加权模型，脚本计算，可复现 |
| 舆论判断 | "这本书很受欢迎" | 区分「口味分歧」与「质量硬伤」，识别营销号通稿 |
| 信息可信度 | 不区分 | 四档标注：已核实 / 待核实 / 信息不全 / 来源不明 |
| 不满意怎么办 | 重新问一遍 | 五类修正路径，只改需要改的部分 |

## 核心能力

- **结构化访谈**：首轮 5 项（题材、结构偏好、当前状态、篇幅、雷点），二轮按条件追问，避免一次抛十几个问题
- **四平台必检**：按男频/女频 × 付费/免费 覆盖，检索词必须带平台名前缀，防止被起点系内容垄断
- **四道硬过滤**：已读去重 → 雷点 → 篇幅 → 渠道可及性
- **六维加权打分**：题材 30、相似度 20、篇幅 15、平台 15、舆论 15、更新状态 5
- **舆论六档**：多来源正面 / 正面但讨论少 / 两极分化（口味）/ 两极分化（硬伤）/ 单一来源 / 负面为主
- **主题分散**：同一地理或时代背景最多 3 本，避免"13 本里 5 本都是日本战国"
- **多轮修正**：范围偏移、口味偏移、单本否决、整体不满、细节追问，五类各走最小路径，上限 3 轮
- **合规约束**：只提供正版渠道，不检索、不暗示任何盗版或 TXT 下载源

## 安装

把整个 `novel-recommender` 文件夹放进对应工具的 skills 目录：

| 工具 | 安装位置 |
|---|---|
| WorkBuddy | `~/.workbuddy/skills/novel-recommender/` |
| Claude Code | `~/.claude/skills/novel-recommender/` |
| Codex | `$CODEX_HOME/skills/novel-recommender/` |

或用 Git 直接克隆：

```bash
git clone https://github.com/XOOX911/novel-recommender.git ~/.workbuddy/skills/novel-recommender
```

也可以从 [Releases](../../releases) 下载 zip 解压。

装完无需配置。下次对话里说"书荒了"或"帮我找本小说"就会触发。

## 使用示例

**最简：**

> 书荒了，帮我找本小说

它会先问 4-5 个问题，再出清单。

**带明确偏好：**

> 想看星际战舰类的，100 万字以上，不要有感情线

**换口味：**

> 换，这次看外国历史的

**拿到清单后：**

> 第 3 本我看过 / 第 2 本不合口味，太慢了 / 只要免费的 / 这几本都不对味

以上每种说法都会触发不同的修正路径，不需要重复完整需求。

## 打分模型

满分 100（无参考作品时按 80 分制归一化）：

| 维度 | 权重 | 说明 |
|---|---|---|
| 题材与标签契合 | 30 | 主类型命中 + 细分标签比例折算 |
| 与参考作品相似度 | 20 | 仅在用户给了参考作品时启用 |
| 篇幅契合 | 15 | 目标区间内满分，区间外 30% 内 8 分 |
| 平台可及性 | 15 | 主用平台可直接读满分，需换平台减半 |
| 舆论质量 | 15 | 六档制，详见 `references/source-credibility.md` |
| 更新状态匹配 | 5 | 完结 / 连载 |

打分由 `scripts/rank_novels.py` 执行，不靠模型心算。同一份输入每次输出一致。

```bash
python scripts/rank_novels.py candidates.json --profile profile.json
```

脚本会校验所有字段类型与枚举值，写错时报错退出并指明具体是哪一部候选的哪个字段，不会静默按 0 分处理。

## 兼容性

`SKILL.md` 的 frontmatter 只有 `name` / `description` / `agent_created` 三个字段，不依赖任何私有扩展。理论上任何支持 Agent Skills 规范的工具都能加载。已在 WorkBuddy 上实测。

## 已知局限

- **依赖联网检索**。搜索不可用时会降级，全部标「待核实」并告知用户，不会编造。
- **只覆盖 4 个必检平台**。掌阅、书旗、咪咕等未纳入常规检索，只在查特定书时兜底。
- **舆论判断有主观成分**。六档分档由执行者判定，不是算法结果；同一本书不同人可能判到相邻两档。
- **部分链接需手动核实**。标「待核实」的作品，字数与状态来自二手来源，未逐个打开作品页。
- **description 为中文**，非中文场景下触发率可能偏低。

## 合规

本 skill 只提供正版阅读渠道，**不检索、不提供、不暗示任何盗版站点、破解资源、网盘分享或 TXT 下载渠道**。不绕过任何付费墙、验证码或访问控制。

推荐结果中的书籍信息版权归原作者与平台所有。
